# 🦊 Forest Runner

A fast-paced, 3D forest-themed endless runner built in Unity. Play as a nimble fox dashing through the woods, weaving between three lanes to dodge incoming trees and collect gems as the pace relentlessly accelerates.

## 🎮 Gameplay & Features
* **Three-Lane Endless Runner:** Switch smoothly between left, center, and right forest paths.
* **Dynamic Difficulty:** Movement speed gradually ramps up the longer you survive and the more gems you collect.
* **Collectibles & Scoring:** Gather gems scattered along the trail to boost your score.
* **Obstacle Avoidance:** Dodge trees in increasing difficulty.

## 🕹️ Controls

| Action | Key / Input |
| :--- | :--- |
| **Move Left** | `Left Arrow` |
| **Move Right** | `Right Arrow` |

## 🛠️ Built With
* **Engine:** Unity
* **Language:** C#

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open **Unity Hub** and click **Add** → **Add project from disk**.
3. Select the cloned `Forest-Runner` folder.
4. Open the project, load the main scene inside `Assets/Scenes/`, and press **Play** in the Unity Editor.

## 📁 Project Structure
* `Assets/` – Scripts, 3D models, materials, scenes, and prefabs.
* `Packages/` – Unity package dependencies.
* `ProjectSettings/` – Input, physics, and build configurations.
* `UserSettings/` – Local Unity Editor preferences and layout settings.
